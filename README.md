# 2048 Game

A responsive web implementation of the classic **2048** puzzle game built with Vanilla JavaScript. Slide matching tiles, combine numbers, and try to reach the 2048 tile!

## Live Demo
[Play 2048 Demo](https://owldevcua.github.io/js_2048_game/)

## Design Reference
- [Figma Design](https://www.figma.com/)

## Technologies Used 💻

### Core
* **JavaScript (ES6+)** – Game logic, state management & user controls
* **HTML5** – Game board structure & semantic markup
* **SCSS** – Animations, grid layout & custom styling

### Build Tool & Bundler
* **Parcel** (v2.12.0) – Web application bundler
* **@parcel/transformer-sass** (v2.12.0) – SCSS compilation

### Code Quality & Formatting
* **ESLint** (v8.57.0) – JavaScript linting
* **Stylelint** (v16.7.0) – SCSS/CSS linting & formatting
* **Linthtml** (v0.9.6) – HTML linting
* **Prettier** (v3.3.2) – Code formatting
